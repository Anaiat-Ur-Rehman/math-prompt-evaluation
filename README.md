# Math Prompt Evaluation & Step-by-Step Reasoning Benchmark

### Overview
This project evaluates AI model performance on basic arithmetic, word problems, and everyday mathematical reasoning tasks using structured prompt guidelines.

### Key Components
* **Prompt Design:** Created clear, unambiguous multi-step math prompts to test model logic.
* **Evaluation Rubric:** Designed step-by-step accuracy checklists to verify calculations.
* **Error Analysis:** Categorized common AI calculation mistakes such as rounding errors and percentage miscalculations.
